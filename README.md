# Iorgute 💜

MVP nostálgico inspirado na experiência das comunidades dos anos 2000.

## Execução

```bash
npm install
npm run dev
```

## Importante

Protótipo demonstrativo: conteúdos persistidos no localStorage do navegador. Não há login real, fórum multiusuário ou integração ativa com Supabase. Não adicionar credenciais ao repositório.

Stack: Next.js 15, React 19, TypeScript. Deploy recomendado na Vercel.
